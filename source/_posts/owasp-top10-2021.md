OWASP Top 10 是 Web 安全最经典的入门清单。这篇笔记按 2021 版整理每个风险项的 **核心概念** 和 **防御要点**，方便随时翻阅。

<!-- more -->

## 什么是 OWASP Top 10

OWASP（Open Web Application Security Project）每几年发布一次「十大 Web 应用安全风险」，是业界共识度最高的 Web 风险清单。**2021 版** 共 10 项：

| 编号 | 风险项 | 一句话理解 |
| ---- | ------ | ---------- |
| A01 | 失效的访问控制 | 能看到/操作不属于自己的数据 |
| A02 | 加密机制失效 | 敏感数据明文存、明文传 |
| A03 | 注入 | 用户输入被当成代码/命令执行 |
| A04 | 不安全设计 | 设计层面就缺了安全考虑 |
| A05 | 安全配置错误 | 默认配置、调试接口、错误信息泄露 |
| A06 | 脆弱和过时的组件 | 用了带已知漏洞的框架/库 |
| A07 | 身份认证和认证失败 | 弱口令、会话固定、暴力破解 |
| A08 | 软件和数据完整性失败 | 更新包/反序列化/CI 链路被篡改 |
| A09 | 安全日志和监控失效 | 被打了却没有记录、没有告警 |
| A10 | 服务端请求伪造（SSRF） | 让服务器替攻击者访问内网资源 |

## 重点条目笔记

### A01 失效的访问控制（Broken Access Control）

- **典型问题**：改个 ID 就能看别人的订单（越权）；管理后台没有鉴权；CORS 配置过宽。
- **两个关键词**：
  - **水平越权**：访问同角色其他用户的数据；
  - **垂直越权**：普通用户执行管理员功能。
- **防御要点**：
  - 服务端逐接口做权限校验，**默认拒绝**（deny by default）；
  - 鉴权不要依赖前端隐藏按钮；
  - 资源归属校验：查数据时把「当前用户」写进查询条件。

### A03 注入（Injection）

- **典型问题**：SQL 注入、命令注入、XSS（2021 版把 XSS 归并到本项）。
- **本质**：**不可信数据被解释成了代码**。
- **防御要点**：参数化查询 / 预编译、输出编码、最小权限、输入校验。

### A05 安全配置错误（Security Misconfiguration）

- **典型问题**：默认口令、目录列表、debug 模式上线、Spring Boot Actuator 暴露、报错信息带堆栈。
- **防御要点**：上线前安全基线检查、统一错误页、关闭不必要端口和服务。

### A07 身份认证和认证失败（Identification and Authentication Failures）

- **典型问题**：弱口令、无验证码无限爆破、会话 Token 不过期、找回密码逻辑绕过。
- **防御要点**：多因素认证、限速与锁定策略、密码强度校验、会话过期与注销销毁。

### A09 安全日志和监控失效（Security Logging and Monitoring Failures）

- **典型问题**：登录失败不记录、日志不带时间/IP、被拖库了三天后才知道。
- **防御要点**：关键行为（登录、越权尝试、敏感操作）全量记录 + 告警，日志防篡改。

## 防御视角总结

把十项归纳一下，其实就四件事：

1. **信任边界**：永远不相信用户输入；
2. **最小权限**：进程、账号、数据库都只给必要的权限；
3. **默认安全**：默认拒绝、默认加密、默认关闭调试；
4. **可观测**：出事时能查、能告警、能追溯。
